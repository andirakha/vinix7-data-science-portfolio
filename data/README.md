# Data

| File | Used by | Source |
|---|---|---|
| `Mall_Customers.csv` | Modules 2-6, 9, 10 | [Mall Customer Segmentation Data](https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python) (Kaggle), raw and unmodified |
| `processed/mall_customers_clean.csv` | Modules 4-6 | Generated by `module-03-data-cleaning/data_cleaning.ipynb` from the raw file |
| `auto-mpg.csv` | Modules 7, 8 | [UCI Auto MPG](https://www.kaggle.com/datasets/uciml/autompg-dataset) |

All files are small and committed, so every notebook runs out of the box. To regenerate the cleaned file, re-run `module-03-data-cleaning/data_cleaning.ipynb`.

## Schema of the cleaned file

| Column | Type | Description |
|---|---|---|
| `customer_id` | int | Unique customer identifier |
| `gender` | category | `Male` / `Female` |
| `age` | int | Age in years (18-70) |
| `annual_income_k_usd` | int | Annual income in thousand USD (15-132 after capping) |
| `spending_score` | int | Score assigned by the mall from spending behavior (1-100) |
